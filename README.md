# Lawrenceburg Municipal Utilities – Pre-Job Briefing Form

A mobile-friendly, responsive pre-job safety briefing form that works on PC, Mac, iPad, and iPhone.

## How to view it online (GitHub Pages)

1. **Make the repository public**
   - Go to your repo on GitHub → **Settings** → scroll to **Danger Zone** → **Change visibility** → **Make public**

2. **Enable GitHub Pages**
   - In your repo on GitHub → **Settings** → **Pages**
   - Under *Source*, select **Deploy from a branch**
   - Choose **main** branch and **/ (root)** folder → click **Save**
   - After a minute or two, GitHub will show you a URL like:
     `https://jafoutty-hash.github.io/LAWRENCEBURG-MUNICIPAL-UTILITIES-PRE-JOB/`

3. **Open that URL on any device** — PC, Mac, iPad, or iPhone — and the form will display correctly on all screen sizes.

## Features

- Responsive layout — adapts to any screen size
- Pre-Job job information, crew roster, hazard checklist, PPE checklist, safety topics, and crew sign-off
- Auto-fills today's date and current time
- "Submit & Print" button opens the browser print dialog (works on all devices)
